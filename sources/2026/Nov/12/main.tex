\newsitem{德国经济增长预期上调，财政问题未消失}{经济政策｜11月11日}{
德国经济专家委员会将2026年增长预测提高至1.3\%，预计2027年增长1\%。德国央行行长也认为制造业订单及公共投资正在支持复苏。两则消息相互印证增长改善，却并非完全独立的经济实测：预测依赖假设，而消费偏弱、人口老龄化、财政长期缺口仍是风险。不能将增长预测直接表述为已实现的增长率。\cite{reutersgerman,reutersbundesbank}
}
\newsitem{赫拉探测器靠近被撞击的小行星}{航天｜11月11日}{
据美联社，欧洲航天局Hera探测器开始近距离检查Didymos及其卫星Dimorphos，观测距离约25至30公里。2022年NASA的DART探测器曾撞击Dimorphos并改变其轨道。Hera的任务不是再次撞击，而是调查撞击坑、碎石和小行星内部结构，从而将一次成功的轨道偏转实验转化为更可推广的行星防御知识。报道中的距离是当前观测量，不能与未来计划的更近距离混同。\cite{aphera}
}
